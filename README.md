# Enterprise Security Homelab

A self-built lab environment progressing from identity/attack-path
analysis toward detection engineering and network security, built as
a hands-on portfolio of security operations work, not just a
certification-focused exercise.

## Projects

- [Project 1 = Enterprise AD Security](./project-1-ad-security/) —
  Active Directory attack path discovery and remediation using
  BloodHound. **Complete.**
- Project 2 = Detection Engineering (Nov 2026) — Wazuh, Sigma, Atomic
  Red Team, MITRE ATT&CK mapping. Coming soon.
- Project 3 = Network Security (Dec 2026) — Nmap, Wireshark, traffic
  analysis. Coming soon.

## Philosophy

Each project follows the same cycle: **Attack → Detection →
Investigation → Findings → Remediation → Retest.** The goal isn't to
demonstrate that a tool was used, it's to show a complete, evidenced
security workflow, the same way a real assessment or SOC engagement
would be documented.
